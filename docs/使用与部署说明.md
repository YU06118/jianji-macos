# 简记 · 使用与部署说明（macOS）

> 本文面向 macOS 版仓库 `YU06118/jianji-macos`（版本 0.1.8）。Windows 安装包的构建与发布属于 `YU06118/jianji-desktop` 仓库，本文不再重复，相关步骤在本仓库不适用。

## 一、macOS 桌面端（.app / .dmg）

### 1.1 环境要求

| 项 | 要求 |
|---|---|
| 系统 | macOS 11.0（Big Sur）及以上 |
| 构建工具 | Xcode Command Line Tools：`xcode-select --install` |
| Node.js | 18+（CI 使用 22） |
| Rust | 通过 rustup 安装稳定版工具链 |
| 架构 | Intel（x86_64）与 Apple Silicon（aarch64）分别构建 |

### 1.2 从源码构建

```bash
cd desktop
npm install

# Intel
npm run tauri build -- --target x86_64-apple-darwin

# Apple Silicon
npm run tauri build -- --target aarch64-apple-darwin
```

产物位于 `desktop/src-tauri/target/<target>/release/bundle/`：

- `dmg/*.dmg`：分发包（即发布到 Release 的文件）
- `macos/*.app`：应用本体
- `macos/*.app.tar.gz` 与 `*.app.tar.gz.sig`：自动更新用压缩包与 minisign 签名

> 当前配置 `bundle.targets` 为 `["app", "dmg"]`，`macOS.signingIdentity` 为 `null`，即**不签名、不公证**。
> 本地 release 构建若因系统安全软件变慢，可先用 `npm run tauri build -- --debug --target <target>` 调试。

### 1.3 安装与首次打开（Gatekeeper）

1. 下载与机型匹配的 DMG：Intel 机器用 `x64`（`x86_64-apple-darwin`），Apple Silicon 用 `aarch64`。
2. 打开 DMG，把「简记.app」拖入 `/Applications`。
3. 首次打开（应用未签名，系统会拦截）：

   - Finder 中右键「简记.app」→「打开」→ 在提示框再次点「打开」；
   - 或终端执行：`xattr -dr com.apple.quarantine "/Applications/简记.app"`；
   - 也可在「系统设置 → 隐私与安全性」中点击「仍要打开」。

4. **自动更新的前提**：应用必须位于 `/Applications` 下；从 DMG 直接运行或放在其他目录时，更新下载安装会失败。

### 1.4 数据目录

应用会在以下目录创建数据文件：

```
~/Library/Application Support/com.jianji.ledger/
├── jianji.db      SQLite 数据库（收支记录、分类、设置）
└── images/        小票图片
```

数据与程序目录分离，覆盖安装/自动更新不会丢数据。

### 1.5 从 Windows 端迁移数据

1. 在 Windows 端（`jianji-desktop`）打开「设置」→ 导出 JSON 备份，得到备份文件。
2. 在 macOS 端「设置」→ 导入备份，选择该 JSON 文件。
   - 导入为**全量替换**（记录 + 分类），导入前请先导出一次 macOS 端现有数据作为保险。
3. 如需保留小票原图：把 Windows 端 `%APPDATA%\com.jianji.ledger\images\` 内的文件复制到 macOS 端 `~/Library/Application Support/com.jianji.ledger/images/`。
   - JSON 备份只含记录与分类（记录中的图片字段是相对文件名），不含图片文件本体。
4. 设置项（主题、提醒时间、更新源等）不在备份内，需要在 macOS 端重新设置。

### 1.6 功能

- **概览**：本月收入/支出/结余卡片、收支趋势、支出分类环形图、最近记录、月份切换
- **明细**：全部流水、按日期分组、删除进回收站、关键词/类型/金额筛选、编辑记录、查看小票原图
- **统计**：周/月/年/近3年/近5年切换、分类柱状图、日历热力图
- **分类**：预设 + 自定义分类（预设可编辑不可删，自定义可删）
- **设置**：外观三档、每日记账提醒（可自定义时分，默认 21:00，仅应用运行时提醒）、自动检查更新、CSV 导出、JSON 备份/导入
- **记一笔**：系统输入法金额输入、收支切换、分类、备注、日期、小票图片

### 1.7 自动更新

启动约 3 秒后后台检查新版本，也可在设置页手动「立即检查」。更新包经 minisign 签名校验后安装并自动重启。机制、故障处理与回滚见 `docs/热更新设计与使用说明.md`。

## 二、与其它仓库的关系

| 仓库 | 内容 | 与本仓库关系 |
|---|---|---|
| `YU06118/jianji-desktop` | Windows 桌面端（Tauri v2 + SQLite） | 本仓库的基线来源；Windows 安装包继续由该仓库发布 |
| `YU06118/jianji-macos` | macOS 桌面端（本仓库） | 双架构 DMG、GitHub Releases 自动更新 |
| `YU06118/jianji-miniprogram` | 微信小程序端 | 小程序的使用、部署与提审说明见该仓库文档 |

三端数据格式一致，可用 JSON 备份在桌面端之间迁移；小程序端的云同步、扫码迁移等能力不在本仓库内。
