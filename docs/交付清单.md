## 二、构建产物（双架构）

推送 `v*` 标签后由 CI 产出，资产名统一为 ASCII：

| 架构 | 构建 target | 交付文件 |
|---|---|---|
| Intel | `x86_64-apple-darwin` | `jianji_<version>_x64.dmg`、`jianji_<version>_x64.app.tar.gz`、`jianji_<version>_x64.app.tar.gz.sig` |
| Apple Silicon | `aarch64-apple-darwin` | `jianji_<version>_aarch64.dmg`、`jianji_<version>_aarch64.app.tar.gz`、`jianji_<version>_aarch64.app.tar.gz.sig` |
| 更新清单 | — | `latest.json`（含 `darwin-x86_64` / `darwin-aarch64`） |

本地构建产物路径：`desktop/src-tauri/target/<target>/release/bundle/dmg/` 与 `.../bundle/macos/`。

## 三、快速开始

1. **安装**：到 GitHub Releases 下载与机型匹配的 DMG（Intel → `x64`，Apple Silicon → `aarch64`），把「简记.app」拖入 `/Applications`。
2. **首次打开**：应用未签名，右键「简记.app」→「打开」；或执行 `xattr -dr com.apple.quarantine "/Applications/简记.app"`。
3. **查看原型**：双击 `prototypes/简记-桌面端原型.html`。
4. **从源码构建**：克隆 `git clone https://github.com/YU06118/jianji-macos.git`，在 `desktop/` 下 `npm install` 后执行 `npm run tauri build -- --target <target>`，详见 README。

配置完成后推送 `v*` 标签即可自动发版；`workflow_dispatch` 只上传 artifacts，不发布 Release。
